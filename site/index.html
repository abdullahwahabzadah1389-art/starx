StarX

by Sm0ke

A web proxy you run yourself. Pages are fetched by your own server and rendered inside StarX, with a games shelf of 235 titles tucked in alongside.

View the source Deploy your own

A note on this page. This is a static overview, not the running app. StarX needs a server with service-worker support to proxy anything, so the live proxy runs on a host like Vercel rather than here. The steps below get you a working copy.

What it does

Two things, really.

Browses through your server

Traffic is fetched server-side and rewritten, so pages render inside StarX instead of navigating away.

Plays games in place

235 titles load in the same frame — from quick arcade games to cloud-streamed Roblox.

Handles stubborn sites

Security headers that break proxied pages get stripped, and Cloudflare-gated sites often work where a plain fetch fails.

Stays out of your way

Its own tab, its own addresses, its own logo. No external branding on the pages you visit.

Put it online

Roughly five minutes, if you have a Vercel account.

  1. Fork or download the repo: github.com/abdullahwahabzadah1389-art/starx
  2. Import that repository at Vercel. It detects Next.js on its own — no build settings to change.
  3. Deploy. Your StarX will be live at the address Vercel gives you.
  4. Prefer a custom domain? Add it under Settings → Domains in the Vercel project.

Do not deploy this to a host that blocks service workers — a plain static host will show the StarX interface but no site will load.

Why Vercel and not a static host

The proxy depends on one browser feature that static hosts switch off.

What works today

Measured by opening each site through a running copy, not by reading about it.

✓ Common sites

Wikipedia, GitHub, ChatGPT, Gemini, Twitch, Spotify, Instagram, TikTok and Discord all render in the proxy.

✓ Roblox on CloudMoon

Sign-in, server choice and streaming all work inside the frame — a live 720p stream, not a redirect out.

✓ The games shelf

All 235 cards load with covers. Dead links were replaced with working copies rather than removed.

Known limits

X.com blocks the public relays. A few heavy games still fail to start, and sites with aggressive bot checks sometimes refuse.
